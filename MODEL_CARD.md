# RuBERT-tiny2: категория товара маркетплейса (39 классов)

Классификатор карточек товаров русскоязычного маркетплейса по категории верхнего уровня
(`greatgrandparent_category`). Дообучена модель [cointegrated/rubert-tiny2](https://huggingface.co/cointegrated/rubert-tiny2)
(~29 млн параметров) с взвешенной кросс-энтропией.

## Как использовать

```python
from transformers import pipeline

clf = pipeline("text-classification", model="theal1ve/marketplace-rubert-tiny2-category", top_k=3)
clf("Корм для кошек сухой, 10 кг")
```

Вход: название товара, при наличии с описанием (`title + " " + description`, без HTML-тегов), до 256 токенов.

## Данные

[nyuuzyou/ke-products](https://huggingface.co/datasets/nyuuzyou/ke-products): после удаления строк без целевой категории
1 401 862 карточки, 39 классов. Стратифицированное разбиение 90/5/5 (train 1 261 675 / validation 70 093 / test 70 094), seed 777.
Классы сильно несбалансированы: от 205 до 190 676 карточек.

## Обучение

- Вход: `title + description` (HTML удалён), `max_length=256`.
- Loss: взвешенная кросс-энтропия, веса классов `sqrt(N / (K * n_c))`, нормированные на среднее и ограниченные диапазоном [0.5, 5].
- Оптимизатор: AdamW, learning rate 2e-5, weight decay 0.01, линейное расписание, warmup 10%.
- Батч 16, 5 эпох; лучший чекпоинт выбран по Macro F1 на validation.

## Ограничения

- Таксономия шумная: часть категорий пересекается по смыслу («Одежда» и «Детская одежда», «Электроника» и «Смартфоны и телефоны»),
  у дословно одинаковых карточек метки иногда расходятся. [УТОЧНИТЬ цифрами из results/taxonomy_noise.json]
- Основные ошибки: пары семантически близких категорий (подробности в README проекта).
- Модель обучена на карточках одного маркетплейса и русском языке; на других площадках или языках качество не проверялось.
- Редкие классы (меньше 1 000 карточек) оцениваются на малом числе примеров, их F1 нестабилен.
- Не предназначена для принятия решений с юридическими или финансовыми последствиями без проверки человеком.
